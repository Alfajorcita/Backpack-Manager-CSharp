# Backpack Manager – C# Console Application

Description

A simple console application developed in C# as part of a programming course.

The program allows users to manage the contents of a virtual backpack through an interactive menu.

Features

Add items to the backpack.

Display the stored items.

Clear the backpack's contents.

Exit the application.

Handle invalid menu selections.

Technologies

C#

.NET Console Application

Programming Concepts

This project demonstrates basic programming concepts, including:

Variables and data types

while loops

switch statements

User input with Console.ReadLine()

Input conversion with Int32.TryParse()

Conditional statements

About the Project

This project was created as a beginner programming exercise to practice control flow, user interaction, and basic data management in C#.
